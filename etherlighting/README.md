# Etherlighting

Discover MAC addresses on your UniFi switch and choose their port colors. Includes a live port map, saved rules, brightness, presets, and shared-port checks.

Hardware tested: USW Pro Max 48 PoE, firmware US2.7.5.15. Experimental profiles: Pro Max 16, 24, and 48, with and without PoE, using model-specific port counts and checked RGBW interfaces. Other model/firmware combinations in that family require Allow experimental models and an observed ten-second color/restoration test. Pro XG and other families are not supported. LED control defaults to off. Read the Documentation tab for setup and recovery.
