# Etherlighting

Discover MAC addresses on your UniFi switch and choose their port colors. Includes a live port map, saved rules, brightness, presets, and shared-port checks.

Target: USW Pro Max 48 PoE, firmware US2.7.5.15. Live discovery, saved rules, and a physical magenta test with automatic restoration have been verified. LED control defaults to off for new installations. Use the ten-second test to check your chosen colors. Read the Documentation tab for setup and recovery.
